Anton Keyboard

AI-powered Android Keyboard

Anton Keyboard — собственная Android-клавиатура с искусственным интеллектом, индивидуальным дизайном и интеллектуальными функциями.

Основные возможности

- Русская и английская раскладки.
- AI-помощник.
- Исправление орфографии и пунктуации.
- Умные подсказки.
- Перефразирование текста.
- Настраиваемые темы и цвета.
- Тёмный и светлый режимы.
- Голосовой ввод.

Технологии

- Kotlin
- Android SDK
- Android Input Method Service (IME)
- Gradle
- GitHub Actions

Разработка

Проект разрабатывается поэтапно.
